## How it works

The favicon is selected randomly on every page load via a tiny inline `<script>` in `index.html` (runs before the page paints, so no flicker):

```html
<link rel="icon" id="faviconLink" href="assets/logo.svg" type="image/svg+xml"/>
<script>
(function(){
  var favs=["fav-01-om-gold", ... ];
  var pick = favs[Math.floor(Math.random() * favs.length)];
  document.getElementById("faviconLink").href = "favicons/" + pick + ".svg";
})();
</script>
```

---

## Pin a specific favicon

To lock in one favicon instead of random, replace the `<link rel="icon">` block in `index.html` with:

```html
<link rel="icon" href="favicons/fav-07-om-squircle-gold.svg" type="image/svg+xml"/>
```

---

## Add a new favicon

1. Create your SVG in this folder — name it `fav-25-your-name.svg`
2. Add `"fav-25-your-name"` to the `favs` array in `index.html` (search for `fav-01-om-gold`)
3. Add a row to the table above

All favicons use `viewBox="0 0 32 32"` — keep that consistent.
